## 二、一键还原与快速恢复

所有移出的资源文件均完整保存在归档目录中，未对文件内容做任何修改。若未来需要制作新活动、开放新资料片或开发测试，可随时通过以下方式**毫秒级原样还原**：

### 方法 1：执行自动化脚本
在客户端根目录直接运行：
```bash
cd /home/tetsuya/mir2ei && ./restore_archived_assets.sh
```

### 方法 2：手动单文件按需拿回
例如某天需要重新引入“神舰”或“雪原”怪物时，直接将对应文件移回 `Data/` 目录：
```bash
mv /home/tetsuya/mir2ei_archive/Data/Mon-53.Zl /home/tetsuya/mir2ei/Data/
```
