# 客户端深度体积分析与二次极简瘦身方案 (Client Slimming Analysis & Plan)

## 一、为什么客户端当前仍有 7.1 GB？（深度解密）

当年 2003 年光通《传奇3》光盘安装包仅约 700MB，解压后仅约 1.5GB。而目前我们的客户端在移出第一批 3.3GB 后仍有 7.1GB。通过对当前全量文件的格式、尺寸与引用分析，发现四大核心膨胀来源：

| 膨胀模块 | 当前占用 | 核心原因与事实 | 目标瘦身空间 |
| :--- | :---: | :--- | :---: |
| **1. 双份图库格式冗余** | **~ 3.5 GB** | `LegacyEI/Data/`（.wil 原版 1.56GB）与 `Data/`（.Zl 现代版 4.0GB）同时存在，地砖（Tilesc）、建筑房屋（Object1c/2c）、沙漠森林地砖、男女裸模动作完全重复存放了两套。 | **可减 1.5~2.0 GB** |
| **2. 地图文件数量暴增** | **759 MB** | 原版经典地图仅约 100 张，当前 `Map/` 目录下存放了 **794 个 `.map` 文件**，包含大量雪原、地下魔宫、修罗、冰原及私服无用地图。 | **可减 500 MB** |
| **3. 未压缩的高清音效** | **689 MB** | `Sound/` 目录下存放了 **696 个未压缩的 `.wav` 无损大音频**，包含了大量后期怪物吼叫与非经典特效音。 | **可减 400 MB** |
| **4. 残留巨无霸单体包** | **~ 600 MB** | `Mon-60.Zl` 单文件高达 296MB、`MagicEx5.Zl` 100MB、男女时装 `Costume` 103MB、高阶时装衣服 87MB 等。 | **可减 600 MB** |
| **合计可瘦身潜力** | — | — | **~ 3.0 ~ 4.0 GB** |

> **最终精简目标**：将 `mir2ei` 客户端整体压缩控制在 **2.0 ~ 3.0 GB**，真正重现当年传奇3经典版的轻巧体量。

## 二、当前客户端完整备份（安全屏障）

在进行任何二次移出操作前，已使用 Linux 文件系统硬链接（Hard Link Snapshot）对当前 7.1GB 客户端创建了 100% 完整物理快照备份：
- **备份快照目录**：`/home/tetsuya/mir2ei_backup_20261003_7gb/`
- **特性**：毫秒级生成，即使原客户端目录删除或修改任何文件，备份目录完全不受影响，随时可以通过一条命令瞬时复原。

### 一键复原命令
```bash
# 紧急情况下，若需完全恢复至 7.1GB 初始状态：
rm -rf /home/tetsuya/mir2ei
cp -al /home/tetsuya/mir2ei_backup_20261003_7gb /home/tetsuya/mir2ei
```

## 三、二次极简瘦身分步实施策略

### 阶段 1：剥离未引用的巨无霸拓展单体包（立减 ~600MB）
1. `Mon-60.Zl`（296MB）与 `Mon-59.Zl`（51MB）移入归档；
2. `MagicEx5.Zl`（100MB）与 `MagicEx10.Zl`（55MB）移入归档；
3. `M-Costume.Zl` 与 `WM-Costume.Zl`（103MB，经典版无时装）移入归档；
4. `M-HumEx2.Zl` 与 `WM-HumEx2.Zl`（87MB，后期衣服）移入归档。

### 阶段 2：精简地图资产（794张 $\to$ 经典地图，立减 ~500MB）
- 基于当前纯净版 `System.db` 中有刷怪点和连接关系的真实经典地图，将无引用的 600+ 张后期废弃地图归档至 `mir2ei_archive/Map/`。

### 阶段 3：图库单套化与音效优化（立减 ~2GB）
- 确立图库首选路线，消除 `.wil` 与 `.Zl` 在地砖与物体上的双重存放；
- 梳理音效，剔除非经典怪物音频。
