## 8. 严格的提交/推送协议（本任务最重要）

用户要求：**任何一个小功能/小差异做完，就立即提交一次并推送一次，然后才开始下一项。**

每项流程固定为：

```bash
git diff --check
dotnet build GodotClient/ZirconClient.csproj --no-incremental   # 本项改 C# 时
# 只暂存本项自有路径
git add <本项精确路径>
git diff --cached --check
git diff --cached --stat
git commit -m "修复/对齐：<具体小项>"
git push origin master
git rev-parse HEAD
git ls-remote origin refs/heads/master
```

若 push 失败或远端非预期变化：停止该项及后续写操作，保留本地 commit，不 force push；把错误与两端 SHA 如实报告。不要使用 `git add -A`。如果本项只改变文档，也必须单独提交并推送。不得把代码、报告、别人的 WIP 捆成一个大提交。
