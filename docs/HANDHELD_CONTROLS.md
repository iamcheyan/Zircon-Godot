# Zircon TG5040 掌机按键设计与操作手册

适用设备为 TrimUI Smart Pro（TG5040），适用于启用掌机模式的 Zircon Godot 客户端。本文记录 2026-11-24 讨论确认的操作方案，结合仓库中的动作绑定和 Select 大地图实现整理。设计来源见 [chezmoi #170 掌机版输入系统实现方案](https://github.com/iamcheyan/chezmoi/issues/170)。

## 1. 游戏中每个键怎么用

| 实体按键 | 怎么按 | 游戏中的动作 |
|---|---|---|
| 左摇杆 | 往要走的方向推，松手回中 | 八方向移动。起步走一段，持续推进后在地形、负重和角色状态允许时连续跑。松手后停止发起新的移动，已发出的移动段正常结束。 |
| 右摇杆 | 往目标方向推 | 选中附近的怪物、NPC、掉落物或其他玩家，供后续操作使用。选中本身不会攻击，右摇杆不控制鼠标。 |
| **A** | 短按并松开 | 对选中的怪物普通攻击、与 NPC 对话、拾取掉落物。无有效目标时先用右摇杆选目标。普通攻击不再占用 Y。 |
| **B** | 短按并松开 | 取消当前操作、清除目标和锁定、停止自动跑等。打开菜单或对话时，B 用于取消或返回。 |
| **X / Y** | 按下即触发一次 | 执行当前动作页的 X / Y 绑定。长按不自动连发。 |
| **↑ / ↓ / ← / →**（十字键） | 按下即触发一次 | 执行当前动作页相应方向的绑定。四个方向各占一格，↑ 和 ↓ 不再默认打开技能或腰带选择器。 |
| **L1 / R1** | 单独按下再松开 | 在第 1 页和第 2 页之间切换。两页时单按任一键都切到另一页。 |
| **L2 / R2** | 各自短按，或各自按住 | 每个扳机各有两个固定快捷位。短按在松手时触发，长按到阈值时触发一次。 |
| **L1＋R1** | 第一键未松开时立即按下另一键 | 执行第 5 个固定快捷位。识别为组合后，两键都不翻页。 |
| **L2＋R2** | 第一键未松开时立即按下另一键 | 执行第 6 个固定快捷位。识别为组合后，两键的单独短按和长按均不执行。 |
| **L3** | 按下左摇杆 | 开关自动跑步。再按 L3 或按 B 可停止。在操作绑定页用于打开时间设置。 |
| **R3** | 按下右摇杆 | 锁定或解锁当前目标。没有选中目标时会先尝试选一个附近目标。已锁定时右摇杆不会换目标，目标失效后锁定会清除。 |
| **Start** | 短按 | 在默认 HUD 和 F2 掌机 HUD 间切换。切换画面布局不改变这套掌机按键。 |
| **Select** | 短按并松开 | 开关当前全屏大地图。地图也可用 B 关闭。 |
| **Select** | 在游戏中按住约 600 ms | 开关地面掉落物名称。这个时长独立于 L2/R2 的长按设置。 |
| **Menu / Mode** | 短按 | 打开全屏手札，在手札主界面再按可关闭。正在处理 NPC、交易等窗口时，先用 B 返回。 |

目标信息不再放在顶部中间，而是右下角目标卡：左侧是怪物头像（无头像时使用它自己的待机形象）或物品的背包图；右侧显示名字、等级/数量及已知属性。怪物血量未知时明确显示未知，基础属性不代表运行时增益后的数值。目标死亡或取消选择后目标卡消失。窄屏空间不足时，卡片上移到动作格上方，不遮住操作。

右摇杆按输入方向给候选排序。当前实现同时考虑夹角和距离，方向更接近的目标通常优先，较近的目标也会得到加分。需要专注一个目标时，先用右摇杆选中，再按 R3 锁定。A 的普通攻击适用于可攻击的怪物。需要指定施法目标时，先选中目标，再按绑定该技能的键。

## 2. 动作栏和固定快捷位

**两页 × 六格，加六个固定快捷位，共 18 个可配置位。** A、B、摇杆、Start、Select、Menu 属于常驻操作。

- **右下动作栏**显示当前页的 X、Y、↑、↓、←、→ 和页码状态。翻页后换成另一组六个动作，空槽按下不会执行动作。
- **左下固定快捷区**显示 L2/R2 的短按、长按以及两组组合键。左下六格不随翻页改变，适合放需要随时触发的动作。按住扳机可查看短按、长按、组合的绑定提示和按住进度。
- **F2 主 HUD**同时保留左上的角色资源与增益、右上的圆形小地图。左上依次是红色生命条、蓝色魔法条、黄色经验条；经验条显示本级百分比与「当前经验/升级所需」，满级显示 MAX。两套 HUD 下的动作绑定相同。旧技能快选、旧腰带快选不是这套战斗输入的默认入口。

| 固定格 | 触发方式 | 首次生成绑定时 |
|---|---|---|
| 1 | L2 短按，松手执行 | 腰带第 1 格有当前可用且受支持的物品时，从该物品生成绑定。 |
| 2 | L2 长按，到阈值执行一次 | 空。 |
| 3 | R2 短按，松手执行 | 腰带第 2 格有当前可用且受支持的物品时，从该物品生成绑定。 |
| 4 | R2 长按，到阈值执行一次 | 空。 |
| 5 | L1＋R1，同时按住 | 默认绑定「打开大地图」。当前这个可绑定功能沿用原大地图入口，Select 打开的是新的全屏地图。 |
| 6 | L2＋R2，同时按住 | 空。 |

首次没有已保存配置时，系统按角色已学且本职业可绑定的技能填入两页，从第 1 页开始，顺序为 X、Y、↑、↓、←、→。技能不足时其余格留空。配置已保存后使用玩家自己的绑定。腰带链接和动作绑定各自保存，初始化时从腰带带入的物品动作可以单独更换。

### 短按、长按与组合冲突

- 默认长按阈值是 **600 ms**，组合识别窗口是 **80 ms**。按组合时，两键必须有真实重叠，第二键也必须在识别窗口内按下。先松开第一键再按第二键会被识别为两次单按。
- L2/R2 长按触发后，松手不会额外触发短按。已经触发的单按或长按不会被随后按下的另一键撤销。
- 识别到组合就只执行组合槽。即使该组合槽为空，也不会补发两侧的单键动作。若第二键恰逢组合窗口与长按阈值的同一边界，组合优先。
- 打开手札、绑定界面、大地图或其他模态窗口，以及游戏失焦时，待执行的战斗输入会取消。退出后，仍按着的键要先松开再按，移动摇杆要先回中。查看手札或地图时游戏世界继续运行。

## 3. 手札里的按键

| 按键 | 手札主界面 | 进入项目操作菜单后 |
|---|---|---|
| **Menu / Mode** | 开关手札 | 关闭手札。 |
| **L1 / R1** | 上一个 / 下一个主标签 | 先按 B 返回再切换。 |
| **L2 / R2** | 上一个 / 下一个分类 | 先按 B 返回再切换。 |
| **十字键 / 左摇杆** | 移动选中项 | 上下选操作。 |
| **右摇杆 ↑ / ↓** | 滚动右侧详情 | 操作菜单期间详情滚动暂停。 |
| **A** | 打开当前项目的操作菜单 | 确认当前操作或进入下一级。 |
| **B** | 返回游戏 | 退回上一级，逐层关闭。 |
| **X** | 次要操作，按当前项目显示的提示执行。支持的背包物品可进入腰带链接。 | 使用 A 确认当前操作。 |
| **Y** | 切换当前列表按名称排序或恢复原顺序。 | 先按 B 返回列表。 |
| **Select** | 短按松开查看全屏大地图，关图后回到原手札页面。 | 先按 B 返回列表。 |
| **Start** | 切换游戏 HUD 布局。 | 退回一级操作菜单。 |

主标签依次为 **背包 → 人物 → 技能 → 任务 → 社交 → 系统**。例如查看装备，可按 Menu 进入手札，在「背包 → 装备」选中物品，按 A 打开操作，再按界面提示选择穿戴或对比。戒指和手镯可选择对应的装备槽。卸下装备从「人物 → 装备」进入。当前装备操作提示受客户端版本影响，以屏幕上的选项名称为准。

**腰带和动作栏用途不同。** 手札腰带用于受支持的药水和卷轴，支持检查链接、使用和解除链接。统一动作栏的「物品」候选按客户端支持的直接使用类型和角色可用状态筛选，范围可包括受支持的消耗品、卷轴、技能书等。衣服等装备走背包的穿戴操作。

NPC、商店、仓库或交易窗口打开后，按方向键选项目，A 确认，B 逐层取消或返回。数量输入和确认框依照当时的屏幕提示操作。

**退出游戏**：按 Menu 打开手札，在「系统 → 显示」的第一项选「退出游戏」，也可从「系统 → 离开」进入。按 A 打开操作，再按 A 进入确认；默认选中「取消」，需选中「确认」再按 A 才会关闭 Zircon 并返回掌机启动器。B 返回上一级。「返回角色选择」不会关闭 Zircon。

## 4. 怎么改绑定

**从技能页直接绑定（掌机）：** Menu → 「技能」 → 选中已学技能 → **A** → 「绑定到掌机动作栏」 → **A** → 选「第 N 页 · X/Y/↑/↓/←/→」或「固定 · L2 短按…」 → **A**。
保存成功后立即生效，本页技能详情会显示「掌机动作栏：第 1 页 X」。列表里的「现在是：…」表示该格当前占用者；同一技能重复绑定到同一格不会清空，改绑其他格后旧格保留，需要时用 X 清空。

技能页的「掌机动作栏」绑定与 PC 的 F1–F12 快捷栏组相互独立；PC 端仍显示「更改该角色共用快捷栏」的按键组列表。


1. 进图后按 **Menu**。用 **L1/R1** 切到「系统」，用 **L2/R2** 切到「操作」。
2. 用十字键或左摇杆选中「操作绑定」，按 **A** 打开操作菜单，选择「编辑掌机按键」并按 **A** 进入。
3. 用 **L1/R1** 切换「第 1 页」「第 2 页」「固定快捷」。用十字键或左摇杆选中要修改的格，按 **A** 打开候选。
4. 在候选页用 **L1/R1** 切换「技能 / 物品 / 功能 / 清空」，方向键选项目。候选超过一屏时，继续向下即可翻到后一屏。
5. 按 **A** 确认替换，保存成功后立即生效。候选页按 **B** 取消本次更改。在绑定主页面可用 **X** 一键清空选中的格。
6. 按 **B** 退出绑定配置，回到手札。再按 **B** 或 **Menu** 回游戏，按对应键验证动作。

可绑定的技能包括已学的主动技能，以及游戏原本支持的开关技能。纯被动技能没有可执行的快捷绑定。可选功能包括互动、取消、切换目标、回到第一页、打开大地图和直达手札六个主标签。使用动作时仍检查职业、等级、耗蓝、冷却、数量、目标等游戏规则。

每个服务器地址、端口和角色分别保存绑定。物品绑定跟随物品种类，背包换格不需要重新绑定。保存出错时会保留原绑定和已生效的时间设置。

### 调整长按和组合窗口

在绑定主页面按 **L3** 打开「操作时间设置」。**↑/↓** 选项目，**←/→** 减少或增加，**B** 返回。每次调整单独保存。

| 项目 | 默认 | 范围 / 步长 |
|---|---:|---|
| L2/R2 长按阈值 | 600 ms | 100–5000 ms，每次调整 50 ms。 |
| 肩键组合识别窗口 | 80 ms | 0 至长按阈值，每次调整 10 ms。 |

比如，可以把常用技能放在第 1 页的 X，把备用技能放在第 2 页的 X，再把药品放在 L2 长按。进图按 X 用当前页对应技能，松开单独按下的 L1/R1 后切页。无论在哪一页，按住 L2 到阈值都会尝试使用同一种药品。

## 5. Select 全屏大地图

- 短按 **Select** 并松开打开当前地图，再短按 **Select** 或按 **B** 关闭。世界中的移动、战斗和鼠标操作在地图打开时不接收。关图后若来自手札，会回到打开前的页面。
- 地图从屏幕顶端开始，无旧窗框，完整地图图像铺到状态栏上方，宽度覆盖整个屏幕。地图素材长宽比与区域不同时会调整宽高以完整显示。地图保持北朝上，白色三角使用小地图同款样式，按角色当前位置和朝向绘制。地图不会随着朝向转动，NPC 和出口等标记仍可见。
- 底部常驻条显示地图名、坐标、角色名、等级、职业、生命、法力，以及有对应上限时的专注。还显示骑乘或异常状态与当前增益图标。没有地图图像的场景仍保留角色状态条。
- 这个全屏地图用于查看位置和状态。任务指路和可绑定的「打开大地图」使用既有入口，由对应界面处理。

## 6. 对照与验收

- 讨论中的「目标分类优先级可配置」暂未接入设置。当前可用的是右摇杆方向选目标和 R3 目标锁定。
- Select 全屏地图要求客户端包含 `6bc2821c` 的改动。较早的动作绑定版本会打开旧式地图。按键手感、用药扣量、实时施法以及重登恢复以装有对应版本的 TG5040 验收为准。
- 实体验收时可用一条完整流程核对：选怪后按 A，绑定 X 后施放，翻页后确认 X 换成另一动作，分别试 L2 短按、L2 长按及 L2＋R2，再打开地图检查三角朝向和状态，关图后重登检查绑定恢复。
