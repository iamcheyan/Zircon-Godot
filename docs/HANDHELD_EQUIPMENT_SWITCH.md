# 掌机手札按部位换装

日期：2026-11-25。范围为掌机手札「人物 → 装备」，不修改 PC 装备窗口、物品规则、数据库或存档。

## 操作

- 方向键或左摇杆选装备部位，A 打开背包候选列表。选头盔只列头盔，选鞋子只列鞋子，空部位同样可以打开。
- 候选包含背包中此部位所有匹配装备，不因不可穿戴而隐藏。等级、职业、性别、属性、伙伴、腕力/负重、鱼竿和锁定等不符合时灰显并标明原因。灰显项仍能选中查看说明，A 不发送穿戴请求。
- 可穿戴项按 A，沿用 `DXItemCell.ToEquipment` 和服务器的物品移动校验，换装结果以回包为准。
- B 关闭候选列表返回人物装备页。已穿戴部位的 X 仍提供卸下操作。左右手镯/戒指按选中的具体部位换装，不自动换到另一只手。
- 背包没有对应物品时显示明确说明。打开列表后若物品或当前装备变化，旧选择不执行，要求重新打开。

## 验证

`HandheldEquipmentSwitchChecks` 使用离线角色和网络待发队列，未连服务器、未改存档：

- 空头盔、空鞋子和已穿戴头盔均能列出对应物品；不混入别的部位。
- 需 30 级而角色仅 10 级的头盔保留在列表，标明等级不足；禁用候选不会发包。
- 职业、性别、负重不符的说明正确。
- 可用候选发到当前部位；RingL/RingR 分别测试。
- 当前装备变化、物品移走后旧回调不发送；空分类有提示；已穿戴部位保留卸下入口。
- 640×360 OpenGL 实际控件截图覆盖灰显、原因、焦点、A 不执行、B 返回。测试角色与物品为夹具，不是掌机实拍。
