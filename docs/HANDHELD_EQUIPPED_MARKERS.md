# 背包里的已穿戴标记

日期：2026-11-25。仅掌机手札展示，不改 PC 背包、物品存储位置或服务器规则。

- 背包「全部 / 装备」显示身上实际穿戴的装备，左上金色「已穿」角标，详情标明具体部位。它们是身上装备的展示项，不是背包新增物品，不占背包容量。
- 同名、同类型的备用装备仍是普通背包物品，不凭名称判断。以装备数组里的真实物品实例/索引为准；短暂双数组引用只显示一份。
- A 在已穿戴项打开对应部位的替换候选；X 沿用卸下操作。不可更换或卸下时按游戏现有条件返回说明。
- 卸下/更换收到结果后，手札重新投影，不保留旧的「已穿」标记；旧条目无法引用另一件同名物品执行操作。
- 下方计数区分「背包 N 件 / 已穿 M 件」，避免把展示项计入真实背包物品数量。消耗品、材料和任务分类不混入穿戴展示项。

验证：`HandheldEquippedMarkersChecks` 9 项状态检查通过，另有实际 640×360 OpenGL 渲染；换装 16 项、背包占格 95 项、退出 8 项复跑通过。测试是离线夹具，不连接服务器、不修改存档。真机版本未在本轮部署。
