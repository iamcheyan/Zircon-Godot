# 旧版 EI HUD 接入正式游戏实施与验收计划

## 目标

将已经在 `LegacyHudLayoutLab` 中验证过的旧版 EI 主 HUD，接入正式 `GameScene`，同时保留正式游戏的网络数据、窗口路由、快捷键和业务逻辑。迁移完成后，测试场和正式游戏必须使用同一套布局定义，避免两套坐标继续漂移。

本计划只覆盖主 HUD：玩家球、状态条、快捷栏、右侧操作按钮、主 HUD 贴图和入口位置。人物、背包、技能、任务等弹窗继续由各自窗口迁移计划负责，不在本计划中复制测试场的静态窗口。

## 实施阶段与审核标准

### 阶段 0：基线与回退点

工作：确认分支、工作树、当前测试场审计结果和正式登录 smoke test；记录迁移前提交。

审核标准：

- 工作树干净，分支和远程一致。
- `dotnet build GodotClient/ZirconClient.csproj --no-incremental` 通过，0 错误。
- `LegacyHudLayoutLab --legacy-audit` 通过。
- `bash login_game.sh` 能完成登录、选角、`StartGame` 和进入地图。
- 若后续阶段失败，可通过开关恢复当前正式 HUD。

### 阶段 1：提取共享布局定义

工作：将测试场已经确认的坐标、尺寸、资源帧和可见性规则集中到共享布局类/定义中。测试场和正式 `MainPanel` 都调用共享定义，禁止复制两套魔法数字。

审核标准：

- 玩家球位置、尺寸为 `(49,13)`、`112×110`。
- 无最大魔法值显示完整红球；有最大魔法值在同一控件显示红蓝球。
- 错误的右侧重复红球 `MCImage` 不可见。
- HUD 主背景、快捷栏、两条状态条和右侧按钮的资源帧与测试场一致。
- 测试场审计仍通过，且独立构建不依赖正式登录数据。

### 阶段 2：接入正式 MainPanel

工作：正式 `GameScene` 使用共享布局初始化 `MainPanel`；保留正式玩家状态、装备、技能、快捷栏和网络事件绑定。增加显式开关，允许旧版 HUD 和当前 HUD 之间回退。

审核标准：

- `--legacy-hud` 能启用旧版 HUD，未指定时仍可启动当前 HUD。
- 真实登录后 HUD 可见，玩家球、HP/MP、经验/负重、快捷栏和按钮位置正确。
- 不再出现重复红球、拉伸、裁切或窗口缩放导致的偏移。
- HUD 不阻塞地图点击、人物移动和鼠标目标选择。
- 关闭客户端或退出地图不会残留服务端进程和 UI 回调。

### 阶段 3：入口、窗口和快捷键回归

工作：逐个验证主 HUD 按钮与旧版窗口的映射；确认快捷键和鼠标点击都使用正式窗口实例，而不是测试场占位窗口。

审核标准：

- 人物、背包、技能、任务、聊天、组队、行会、交易、仓库、设置、公告入口均能打开对应正式窗口。
- 每个窗口的 `LegacyOpen` 类型、尺寸和可见状态符合 `LEGACY_DIALOG_TEST_REPORT.md`。
- F1-F12、Shift+F1-F12、背包/技能/聊天/设置等快捷键不被 HUD 覆盖。
- 打开窗口后人物仍能按既定规则移动；只有拿起物品、拆分或丢弃状态按旧版规则锁定移动。
- 窗口关闭、切换和置顶行为不产生重复实例。

### 阶段 4：真实数据与视觉验收

工作：使用测试账号真实登录，在至少 800×600 和当前桌面缩放下检查 HUD；验证真实 HP/MP、等级、经验、技能和物品数据刷新。

审核标准：

- 真实登录日志包含 `StartGame 成功` 和进入 `TestHero` 地图。
- 两种分辨率下 HUD 比例一致，不强制压扁贴图。
- 玩家球状态切换、状态条填充、快捷栏图标刷新均来自真实数据。
- 主 HUD 截图与旧版参考图逐项核对，不能仅以“程序启动成功”作为视觉通过。
- 不影响地图渲染、物品掉落即时显示、物品闪光和人物默认照明。

### 阶段 5：默认切换、文档和交付

工作：在前四阶段通过后将旧版 HUD 设为正式默认，保留显式现代 HUD 回退开关；更新启动说明、迁移总结、验收报告，提交并推送。

审核标准：

- 默认启动即使用旧版 HUD；回退开关仍可启动当前 HUD。
- 构建、测试场审计、真实登录、窗口直达和视觉检查全部通过。
- 文档列出实际提交、命令、截图路径、已知警告和未纳入范围。
- 工作树干净，提交已推送到 `origin/ui/legacy-layout-lab`。
- 未完成的业务项必须明确列为未完成，不能以布局测试代替业务验收。

## 失败处理与回退

任何阶段出现尺寸、输入、登录或地图渲染回归时，先关闭 `--legacy-hud`/默认切换，恢复当前正式 HUD，再保留失败日志和截图；禁止用临时坐标覆盖共享定义来掩盖问题。
