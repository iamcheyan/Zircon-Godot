# 旧版 UI Layout Lab

这是正式替换前的独立布局实验场。它不打开当前的背包、角色或任务窗口，也不修改现有业务逻辑，只把旧版 `legacy_ui.json` 的窗口作为参考层创建出来。

## 启动

```bash
godot-mono --path GodotClient res://Scenes/LegacyUiLayoutLab.tscn
```

布局实验场使用旧版 800×600 坐标转换到当前 1024×768 逻辑画布。窗口可以拖动，点击后置顶；candidate 窗口半透明，只用于观察，不能作为正式迁移依据。

## 下一步

先在这个实验场确认旧版窗口的层级、尺寸、底图和重叠关系，再将确认后的窗口逐个改造成正式 Godot 控件。实验场与正式窗口完全隔离，因此调整布局不会再次破坏进游戏界面。
