# 旧版 UI 五阶段最终审计

## 功能边界

保留：战士/法师/道士、基础战斗、地图移动、怪物、掉落、背包、装备、NPC、任务、聊天、组队、公会、交易、邮件、自动巡路、自动战斗、套装、宝石、强化/镶嵌、钓鱼、声望和称号。

禁用：刺客新建、隐士、修炼、宠物/伙伴及宠物猪跟随、商城/充值、寄售/拍卖入口、副本 Finder。协议和共享模型暂不物理删除，采用入口、快捷键和服务端边界三层保护。

## UI 审计矩阵

| 功能 | 主界面/窗口 | 快捷键/回调 | 服务端/状态 | 结论 |
|---|---|---|---|---|
| 宠物/伙伴 | 入口由 `CompanionEnabled=false` 拦截，宠物模式标签隐藏 | `CyclePetMode` 直接返回 | 登录状态不恢复宠物模式；请求入口不开放 | 禁用 |
| 修炼 | 角色页签/面板不可见 | 增长请求为空实现 | 既有事件只保留兼容读取 | 禁用 |
| 隐士 | 角色页签/面板不可见 | 无开放入口 | 保留模型兼容 | 禁用 |
| 商城 | CashShop 按钮受 `GameStoreEnabled=false` 控制 | 打开方法受同一开关控制 | 服务端拒绝保护已存在 | 禁用 |
| 寄售 | 入口受 `ConsignmentEnabled=false` 控制 | 打开方法受同一开关控制 | 服务端拒绝保护已存在 | 禁用 |
| 副本 Finder | 入口受 `DungeonEnabled=false` 控制 | 快捷键不能打开 | 服务端拒绝保护已存在 | 禁用 |
| 三职业/基础装备 | 当前窗口与协议保留 | 原有快捷键保留 | 兼容已有角色读取 | 保留 |
| 自动巡路/自动战斗 | 主面板保留 | 快捷键保留 | 原有逻辑未被禁用开关覆盖 | 保留 |
| 套装/宝石/钓鱼/声望/称号 | 相关窗口和数据未被清理 | 原有操作保留 | 未加入禁用列表 | 保留 |
