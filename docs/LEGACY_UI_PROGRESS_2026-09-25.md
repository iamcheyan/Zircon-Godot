## 状态定义

- `[x] 已完成`：当前证据范围内静态、运行、截图、构建和推送均闭合。

- `[ ] 未开始/未完成`：尚未达到可验收状态。
- `[!] 阻塞`：存在资源版本、目标二进制、外部玩家或其它明确阻塞，不能靠继续猜测解决。
